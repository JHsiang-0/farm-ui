# Farm UI v2 现场验收任务

## A001 V2 真实环境与浏览器完整联调验收

- 状态：进行中
- 类型：环境验收
- 范围：不新增 v2 业务代码，不改变 T001–T207 的完成状态；只验证真实部署依赖、真实设备副作用和浏览器完整链路。
- 前置条件：T001–T207 已完成；测试环境已备份；可访问真实 MySQL、Redis、RustFS 和目标打印机；准备隔离的验收账号、文件和任务数据。
- 安全约束：不得在文档、截图、日志或提交中记录密码、Token、管理员密钥、对象存储密钥或打印机凭据；真实打印前必须确认 G-code 无危险动作，急停和复位方案可用。

### 验收子项

- [ ] A001-1 MySQL 迁移与数据一致性
  - 备份目标数据库后，执行对应的幂等增量迁移。
  - 验证 `farm_user.enabled`、批量恢复关联字段、`farm_audit_log` 及相关索引存在。
  - 验证既有账号、打印机、文件、任务数量和关键关联未被破坏。
  - 记录迁移版本、执行时间、备份位置和脱敏校验结果。

- [ ] A001-2 Redis 真实服务链路
  - 验证登录失败计数、账号禁用标记、打印机状态缓存和分布式锁的 TTL/失效行为。
  - 验证禁用/启用后旧会话、`/auth/me` 和 WebSocket 鉴权结果收敛。
  - 如有多实例部署，验证跨实例缓存失效；单实例环境需明确记录限制。

- [ ] A001-3 RustFS 真实对象存储链路
  - 使用临时验收文件验证上传、预览元数据、缩略图、预签名下载和删除。
  - 验证预签名 URL 过期后最多重签一次，CORS/对象不存在/存储不可用错误可区分。
  - 验证数据库保存失败或对象删除失败时的补偿和数据保留策略。
  - 验收结束清理临时对象和临时数据库记录。

- [ ] A001-4 浏览器真实后端完整 E2E
  - 验证登录、`/auth/me`、刷新恢复、ADMIN/OPERATOR 权限和退出。
  - 验证文件上传、文件预览/下载、单任务创建、队列、手动派发、安全确认、启动、历史和恢复入口。
  - 验证浏览器 WebSocket JWT 握手、初始快照、任务/设备增量、断线重连、陈旧态和错误提示。
  - 验收结束清理临时业务数据，不执行未授权的删除或设备控制。

- [ ] A001-5 真实打印机物理链路
  - 先使用无移动、无加热、无挤出的安全探针验证上传、启动、暂停、恢复、取消和急停响应。
  - 在现场人员确认后，使用隔离设备和批准的测试 G-code 验证自然完成、暂停/恢复、取消停止、急停复位和 Farm 任务收尾。
  - 核对设备实际状态、Farm 任务状态、打印机绑定、状态历史、审计日志和浏览器实时展示一致。
  - 无法证明设备已停止时，不得把 HTTP 200 视为物理完成；任务应保留在可核对的中间态。

- [ ] A001-6 证据与验收收口
  - 为每个子项记录命令/API、时间、结果、脱敏截图或日志摘要及异常处理。
  - 汇总未通过项、责任边界和复验条件。
  - 仅当全部子项通过、临时数据清理完成且证据不含敏感信息时，将 A001 标记为完成并创建本地 Git 提交。
